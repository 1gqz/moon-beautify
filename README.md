# Moon Beautify · 月读美化扩展

给 [月读（Moon / book.koplugin）](https://github.com/AnkioTomas/moon) 的首页加吧唧、相框、主题部件包、界面壁纸 / 锁屏壁纸和输入法键盘背景。

**不联网、不改月读本体**。所有补丁都是运行时轻量替换且带兜底——月读升级导致接口变化时，最多是功能失效退回原生外观，不会影响启动。配置存在扩展自己的 `settings/ext.beautify.lua` 里，卸载插件不丢配置。

当前版本 **0.1.4**（见 `_meta.lua`）。插件入口目录为 `moon-beautify.koplugin`；发布包为 `moon-beautify-0.1.4.zip`。

## 0.1.4 更新要点

- 组件背景与顶层图统一按取景选区显示；透明 PNG 保留镂空，普通图片整张盖住组件
- 取消“全部组件通用”背景 / 顶层图，避免不同尺寸组件套同一张图后变形
- 组件配置页重新排版：每个主题只保留一个标题，主题内虚线、主题间实线；并排组合单独显示成员
- “保存当前配置为主题”只生成快照，不再把新主题标成应用中；要切换必须点“应用”
- 界面壁纸只在开启且确实选了图片 / 有图文件夹时收录部件；锁屏壁纸只在启用月读合成锁屏时收录部件
- 主题部件删除逻辑兼容旧包，清理通用背景 / 花边与旧 `comp_all`，避免旧主题里继续出现“全部组件通用”

## 功能一览

### 吧唧组件（最多 4 个独立实例）

像手机上的电子徽章，拟真外观，全部像素级合成。

| 能力 | 说明 |
|---|---|
| **形状** | 圆形 / 圆角 / 直角，倒角、侧影、特效遮罩跟着形状走 |
| **尺寸** | 小 / 中 / 大（占位高度按比例报，改尺寸不会把整页排版顶乱） |
| **图片** | 固定一张，或选一个文件夹（每天一张 / 每次刷新随机） |
| **动图** | GIF / 动态 WebP 逐帧播（0.8 秒一帧，墨水屏节奏；帧多了自动限缓存） |
| **慢速旋转** | 约 24 秒一圈，逐帧平滑推进 |
| **动态特效** | 细闪、雨滴、星星，可多选叠加 |
| **外圈环** | 本体外面再画一圈：双线环（纯程序绘制，任意尺寸不发虚） |
| **叠加素材** | 一张透明 PNG 压在照片上，自动按吧唧形状裁切 |
| **贴图格** | 8 格田字摆法，每格放一张自己的图 |

动画为墨水屏优化：底图只在「角度 / 尺寸 / 素材变化」时重算一次，每帧开销约一次 blit + 几百次 setPixel，刷新节奏 0.8 秒 / 帧，三种特效坐标完全确定性。

**贴图显示规则**：单独一行（满宽）时 8 格全显示；与其他组件并排（半宽）时只显示中间两列，四角格子不画。

### 相框组件（相框 / 相框 2）

像桌面摆的照片框：单图铺满，或多图堆叠成扇形，中间一张最大的彩色图，四周越靠边越小、做透视倾斜，左右滑动翻页。四周倾斜图灰度处理，中心图保持彩色。

### 全局外观增强（设置 → 外观）

- **底栏图标**：把月读底栏任意格子的图标替换成自己的图片
- **组件背景**：给任意首页组件垫背景底图，支持内容提亮，按取景选区显示；各组件尺寸不同，不提供统一背景
- **组件内边距**：逐组件调，把内容往里收 0–24 px，背景 / 顶层图仍铺满整槽
- **组件顶层图**：给单个首页组件叠一张图片，透明 PNG 保留镂空，普通图片整张盖住组件；按取景选区显示，不提供统一顶层图
- **并排组合**：把同一页的两个（或更多）组件合成一行、宽度均分，分页时同组成员保证不被拆开；组件配置页单独显示并排关系
- **输入法键盘背景**：设置图片、内容提亮、取景选区、按键透明度；修正 e-ink 点击白格闪烁
- **界面壁纸**：月读原生 `features.wallpaper` 配置作为部件捕获 / 应用；只有开启且选了图片 / 有图文件夹时才收录部件
- **锁屏壁纸**：月读原生 `features.lockscreen` 配置作为部件捕获 / 应用；只有启用月读合成锁屏时才收录部件

### 取景选区

吧唧 / 相框 / 组件背景 / 组件顶层图 / 键盘背景都能点「取景选区」进全屏拖拽框选：框内拖动、拉四角改大小，底部按钮或双指缩放；没图也能先设比例。统一填满裁边，只显示框中的部分。

老 Kindle（非 MTK）在拖拽时大块黑闪：旧写法无法压住整屏极性交替，改为节流整屏刷新，并把预览图绘制切到规范化后的安全路径。新机器保持原写法不变。反色闪在所有写法下仍可能出现，但已明显减轻。

### 主题包与部件库（设置 → 外观 → 主题）

主题包是「配置 + 图片」的一套，固定目录：

```
.moon/beautify/themes/<主题名>/
    theme.lua    -- return { kind, version=2, name, conf, parts, cover }
    assets/      -- 图片素材，配置里用 @assets/xxx 引用
```

- **当前配置保存为主题**：整套设置连图片快照，保存后不会抢占“应用中”；要切换必须点“应用”
- **导入主题 zip**：解压归档到固定目录，导入后需再点「应用」才切换
- **应用主题**：整包替换外观配置，原生壁纸 / 锁屏部件会同步应用；未保存的本地改动会按主题存档还原
- **部件库**：按类型或按主题分组，7 类部件可单独启用 / 停用 / 删除
- **复制到其他文件夹**：任意含图片的部件都能把图片 / 文件夹搬到 `.moon` 外的普通目录，配置与主题存档同步改路径，之后可安全删除主题包；文件夹会整个递归复制，多张壁纸不会丢

### 其他细节

- **选图器目录记忆**：月读所有选图器（壁纸 / 锁屏 / 吧唧 / 组件背景）共享「上次目录」
- **图标即图片**：任何接受 `Icon` 的地方，name 写成图片路径就自动画图
- **降级自处理**：特效合成失败自动退回最朴素的圆图；布局接管失败自动退回原生竖排；没有配置时补丁零行为

## 安装

1. 需要 KOReader **2026.07+** 且已安装月读（book.koplugin）
2. 下载 `moon-beautify-0.1.4.zip` 并解压
3. 把解压出来的 **`moon-beautify.koplugin` 文件夹**整个放进 KOReader 插件目录（与 `book.koplugin` 同级）
4. 重启月读，在「拓展」页启用 **美化 / Moon Beautify**
5. 首页长按空白处进入编辑态 → 添加 → 选 **吧唧 / 相框** 等组件

## 快速上手

1. 编辑态添加一个吧唧 → 长按它 → 右上角齿轮 → 选一张图
2. 想要每天换图：图片 → 图片来源 → 文件夹里挑一张 → 选目录 → 换图节奏选「每天一张」
3. 想让时钟和吧唧挤一行：设置 → 外观 → 并排组合 → 新建组合 → 依次选两个组件
4. 底栏图标换成自己的：设置 → 外观 → 底栏图标 → 选格子 → 选一张图
5. 分享整套配置：设置 → 外观 → 主题 → 当前配置保存为主题 → 点该主题 → 导出主题 zip
6. 让图片脱离主题包：部件菜单 → 复制到其他文件夹 → 选一个 `.moon` 外的普通目录

主题色板请用月读自带设置，本扩展不重复。

## 已知注意事项

1. **动画要付出墨水屏的代价**：转动或开特效时约每 0.8 秒一次局部刷新，残影程度因机器而异
2. 转动时每次角度变化会重算底图，大尺寸快转在低端机可能吃力
3. 组件是纯展示的，点按无动作
4. 目前只设置 4 个吧唧、2 个相框
5. 老 Kindle 取景拖拽的反色闪无法完全消除，只能减轻
6. 锁屏 / 壁纸部件会把图片路径写进月读原生配置；删除主题包前先确认没有引用其中的图片，或先用「复制到其他文件夹」搬走

## 目录结构

```
moon-beautify/
├── README.md
├── LICENSE
└── moon-beautify.koplugin/
    ├── main.lua                # 入口（月读扩展约定：空容器）
    ├── moon_source.lua         # 扩展描述：组件注册 + 补丁安装时机
    ├── _meta.lua               # 名称 / 版本 / 描述
    └── moonbeautify/
        ├── badge.lua           # 吧唧合成器
        ├── frame.lua           # 相框合成器
        ├── tilt.lua            # 相框透视倾斜
        ├── fit.lua             # 图片填充 / 取景换算
        ├── focus_picker.lua    # 取景选区拖拽（含新旧机器分流）
        ├── bg.lua              # 背景 / 预览图绘制
        ├── deco.lua            # 顶层图与透明 PNG 渲染缓存
        ├── effects.lua         # 细闪 / 雨滴 / 星星特效层
        ├── view.lua            # 组件视图
        ├── slots.lua           # 8 格贴图
        ├── rows.lua            # 并排布局
        ├── patch.lua           # 运行时补丁（图标 / 背景 / 花边 / 键盘等）
        ├── settings.lua        # 设置界面
        ├── pick.lua            # 图片枚举与「每天一张 / 随机」
        ├── parts.lua           # 部件槽位与分组模型
        ├── part_copy.lua       # 图片外搬到普通文件夹
        ├── wallpaper_part.lua  # 界面壁纸原生配置部件
        ├── lockscreen_part.lua # 锁屏壁纸原生配置部件
        ├── theme.lua           # 主题保存 / 应用 / 导入导出
        ├── store.lua           # 配置存取
        ├── zip.lua             # STORED zip 写入
        └── update.lua          # 自动更新
```

本包不含演示素材；贴图、叠加素材、底栏图标、壁纸都需要自备图片。
